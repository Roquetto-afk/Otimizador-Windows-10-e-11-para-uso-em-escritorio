# Otimizador Windows 10 e 11 para uso em escritório

O **Otimizador Windows 10 e 11 para uso em escritório** é uma ferramenta desenvolvida para auxiliar na manutenção e otimização de computadores utilizados em ambientes profissionais e corporativos, priorizando a simplicidade, a estabilidade e a segurança operacional.

Desenvolvido em **Batch, PowerShell e WPF/XAML**, o projeto disponibiliza uma interface gráfica moderna e intuitiva, permitindo que usuários realizem procedimentos básicos de otimização sem a necessidade de conhecimentos técnicos avançados.

## Principais funcionalidades

- **Limpeza de arquivos temporários:** identificação de arquivos `.tmp` com mais de sete dias, com apresentação da quantidade e do espaço ocupado antes da exclusão.
- **Otimização da inicialização:** acesso às configurações de gerenciamento dos aplicativos iniciados automaticamente com o Windows.
- **Ajuste de efeitos visuais:** acesso às configurações nativas de aparência e desempenho do sistema operacional.
- **Limpeza controlada:** confirmação prévia do usuário antes da exclusão de arquivos.
- **Proteção de arquivos:** mecanismos de verificação que evitam a exclusão de arquivos protegidos, modificados após a análise ou localizados em diretórios temporários redirecionados.
- **Interface gráfica intuitiva:** navegação simples, organizada e acessível.
- **Execução portátil:** não requer instalação de programas adicionais em ambientes Windows compatíveis.

## Compatibilidade

- Windows 10
- Windows 11

## Tecnologias utilizadas

- Batch Script (.bat)
- Windows PowerShell
- Windows Presentation Foundation (WPF)
- XAML

## Como utilizar

1. Baixe o arquivo `Otimizador_Escritorio_Windows_10_11.bat`.
2. Execute o arquivo.
3. Selecione a funcionalidade desejada na interface gráfica.
4. Revise as informações apresentadas antes de confirmar qualquer alteração.

## Diferenciais do projeto

Diferentemente de ferramentas que realizam alterações agressivas e indiscriminadas no sistema operacional, este projeto adota uma abordagem conservadora, preservando a autonomia do usuário e priorizando a estabilidade do ambiente de trabalho.

A ferramenta não realiza alterações automáticas no Registro do Windows, não desativa serviços essenciais e não modifica configurações de segurança do sistema.

## Objetivo

Proporcionar uma solução leve, prática e acessível para a manutenção cotidiana de computadores, contribuindo para a produtividade e a eficiência dos ambientes de escritório.

## Aviso

Em ambientes corporativos, recomenda-se observar as políticas internas de tecnologia da informação antes de realizar alterações no sistema. Os arquivos temporários excluídos não são encaminhados à Lixeira.
